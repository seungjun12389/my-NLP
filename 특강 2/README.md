# 특강 2

## Peer Review Template

- 코더: 코더의 이름을 작성하세요.
- 리뷰어: 리뷰어의 이름을 작성하세요.

### PRT (Peer Review Template)

- [ ] **1. 주어진 문제를 해결하는 완성된 코드가 제출되었나요?**
  - 문제에서 요구하는 최종 결과물이 첨부되었는지 확인합니다.
  - 해당 조건을 만족하는 부분을 캡처해 근거로 첨부합니다.

- [ ] **2. 핵심적이거나 복잡한 코드의 주석 또는 docstring을 통해 코드를 이해할 수 있었나요?**
  - 해당 코드가 핵심적인 이유와 기능, 존재 이유, 작동 원리를 설명했는지 확인합니다.
  - 잘 작성되었다고 생각되는 부분을 캡처해 근거로 첨부합니다.

- [ ] **3. 디버깅 기록이나 새로운 시도 또는 추가 실험을 수행했나요?**
  - 문제 원인과 해결 과정, 추가로 수행한 실험이 기록되었는지 확인합니다.
  - 잘 작성되었다고 생각되는 부분을 캡처해 근거로 첨부합니다.

- [ ] **4. 회고를 잘 작성했나요?**
  - 배운 점, 아쉬운 점, 느낀 점이 기록되었는지 확인합니다.
  - 전체 코드 실행 흐름을 이해하기 쉽게 정리했는지 확인합니다.
  - 잘 작성되었다고 생각되는 부분을 캡처해 근거로 첨부합니다.

- [ ] **5. 코드가 간결하고 효율적인가요?**
  - Python 스타일 가이드(PEP 8)를 준수했는지 확인합니다.
  - 코드 중복을 줄이고 함수화 또는 모듈화했는지 확인합니다.
  - 잘 작성되었다고 생각되는 부분을 캡처해 근거로 첨부합니다.

## 리뷰어 회고

- 코드 리뷰 시 참고한 링크와 간략한 설명을 작성합니다.
- 코드 리뷰를 통해 개선한 코드가 있다면 코드와 설명을 작성합니다.
